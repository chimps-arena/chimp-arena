# Neon Cantina (core-nc4): details to keep

Source art: `astro-resources/materials/NFT Properties copy/Astroworld Core/Neon Cantina.jpg`
(1792 x 1008). NOT `public/properties/cantina.png`, which is a generic image for the
Cantina type and looks nothing like this property.

The 3D model (Meshy) gives the structure. Every text, logo and name below is added
in the game as an exact, sharp overlay, because Meshy turns lettering into
scrambled shapes and game textures are too small to read.

"dawvycole"; the team spells it Davvycole)

## Look and light

- Pink/magenta and cyan neon tubes across the facade; amber pendant lamps under the sign.
- Bar counter edge lit pink; back shelves of bottles lit warm amber.
- Industrial pipes and scaffolding around the facade; metal flight-case crates as tables.
